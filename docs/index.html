Hardware

Four sensors, one board

Each sensor covers a different part of the air around you, from comfort to pollution.

Temperature & humidity

DHT22 / AM2302

Ambient temperature in °C and °F plus relative humidity. Alerts below 0 °C or above 45 °C, and below 20 % or above 85 % RH.

GPIO4°C / °F% RH

Barometric pressure

Bosch BMP280 · I²C

Air pressure in hPa for tracking weather fronts. The firmware finds the sensor at either I²C address, 0x76 or 0x77.

SDA GPIO8SCL GPIO9hPa

Air quality

MQ135 gas sensor · analog

Detects NH₃, NOx, benzene, smoke and CO₂ as an Rs/Ro ratio, averaged over 32 samples and smoothed. Lower values mean more gas.

GPIO1Rs/RoADC 11 dB

Particulate matter

Plantower PMS5003 · UART

Laser-scattering dust sensor for PM2.5 and PM10 in µg/m³. Each 32-byte frame is checksum-verified before it's used.

RX GPIO15TX GPIO79600 baud

Status LED

Onboard WS2812 NeoPixel

Shows the board's state at a glance, with no Serial Monitor needed.

Booting Wi-Fi failed Online Serving

Web dashboard + API

ESP32 WebServer · port 80

A responsive dashboard at / with alert banners and a beep, plus a JSON endpoint at /data for your own tools.

GET /GET /data2 s polling

Get started

      
Up and running in five steps

      
You need the Arduino IDE 2.x (or arduino-cli), an ESP32-S3 board and a USB-C data cable.

    

    

      

        
Clone the repository

        
git clone https://github.com/akshajtripathi24-ui/esp32-s3-weather-station.git
cd esp32-s3-weather-station/firmware/weather_station

      

      

        
Install the board package and libraries

        
Add the Espressif boards URL in Preferences and install esp32 by Espressif Systems. Then install these libraries:

        
arduino-cli core install esp32:esp32
arduino-cli lib install "DHT sensor library" "Adafruit Unified Sensor" \
  "Adafruit BMP280 Library" "Adafruit BusIO" "Adafruit NeoPixel"

      

      

        
Add your Wi-Fi credentials

        
Copy secrets.example.h to secrets.h and fill it in. The file is gitignored, so it stays on your machine. Use a 2.4 GHz network.

        
#define WIFI_SSID     "your-wifi-name"
#define WIFI_PASSWORD "your-wifi-password"

      

      

        
Flash the ESP32-S3

        
Select ESP32S3 Dev Module, set USB CDC On Boot → Enabled, pick your port and click Upload.

        
arduino-cli compile --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc .
arduino-cli upload  --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc -p COM5 .

      

      

        
Open the dashboard

        
Open the Serial Monitor at 115200 baud, press RST and copy the IP address it prints. Open it in any browser on the same network.

        
# Serial Monitor output
Connected! IP Address: http://192.168.1.42

# Raw readings
curl http://192.168.1.42/data
